# @folio/mobile

Expo (React Native) client for folio.

## Status: on hold

Mobile development is paused for now. The package remains in the monorepo for a future restart, but it is **not** an active target.

For day-to-day work, focus on `apps/web`, `apps/api`, `apps/desktop`, and `apps/extension`. Agents and global tasks should skip this directory unless mobile is explicitly requested — see [`AGENTS.md`](./AGENTS.md).
